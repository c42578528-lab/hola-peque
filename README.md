# Hola Peque

Aplicación educativa infantil pensada para niñas y niños que todavía no saben leer.

Incluye actividades visuales y narradas de animales, colores, formas, números y vocales, además de canciones, cuentos y el juego «¿Dónde está?». La interfaz está adaptada para ordenador, tableta y móvil.

## Ver la aplicación

La versión web se publica automáticamente mediante GitHub Pages.

## Ejecutarla en local

```bash
npm install
npm run dev
```

La aplicación infantil está en `public/app/`.
